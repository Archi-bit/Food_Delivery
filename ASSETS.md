# Изображения и карта

JPEG в media генерируются оригинальным кодом `backend/restaurants/management/demo_art.py` средствами Pillow. Внешние фотографии, логотипы и платные сервисы не используются. Иллюстрации нейтральные и предназначены для этого учебного проекта. Seed сохраняет их локально; повторный запуск не создаёт дополнительные копии. Emoji в интерфейсе отображаются системным шрифтом устройства.

Leaflet и OpenStreetMap используются для необязательной карты по явному нажатию пользователя. Атрибуция OpenStreetMap contributors видима; стандартные HTTPS тайлы кешируются браузером, без prefetch, offline download, геокодирования и платных API. [Правила тайлов OSM](https://operations.osmfoundation.org/policies/tiles/). При ошибке сети доступен локальный выбор учебных адресов. E2E блокирует tile requests и проверяет этот fallback, не создавая нагрузку на OSM.
