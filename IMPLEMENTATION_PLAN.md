# План реализации
1. Аудит существующих моделей, маршрутов и тестов; резервная копия SQLite.
2. Перенос существующего Django в backend без изменения миграций.
3. Настройки окружения, безопасность, атомарная корзина, отдельные demo endpoints.
4. Идемпотентный seed: 16 ресторанов, локальные авторские иллюстрации.
5. React: каталог, меню, JWT, корзина, checkout, профиль, отзывы, история.
6. PostgreSQL, Gunicorn, Docker Compose и Nginx; инструкции HTTPS/AWS.
7. Backend/frontend и интеграционные проверки; честный отчёт ограничений.

Архитектура: same-origin proxy устраняет необходимость permissive CORS. Браузерный вход сохраняется серверной сессией Django с HttpOnly cookie и CSRF-защитой; JWT access восстанавливается после обновления и хранится только в памяти. Mock payment хранится отдельно от Order и доступен исключительно в DEMO_MODE. SQLite остаётся вариантом отдельного локального запуска, PostgreSQL — в Compose.
